# What is a Technology Stack?

A Technology Stack is the list of all technologies, programming languages, frameworks, libraries, databases, and tools that we will use to build the project.

Think of it as answering this question:

"Which tools are we using to build our project?"

# Why do we need it?

It helps developers understand:

Which programming languages will be used.
Which frameworks will be used.
Which database will be used.
Which AI libraries will be used.
Which tools need to be installed.
