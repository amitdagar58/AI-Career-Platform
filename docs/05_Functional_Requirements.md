# What are Functional Requirements?

Functional Requirements describe what the system should do.

Think of them as the features of the application.

Examples:

User can register.
User can log in.
User can upload a resume.
System analyzes the resume.
System recommends jobs.

These are all functional requirements.

---

# 1. Introduction

This document defines the functional requirements of the AI Career Platform. These requirements describe the features and capabilities that the system must provide to users.

---

# 2. User Management

The system shall allow users to:

- Register a new account.
- Log in securely.
- Log out.
- Update profile information.
- Change password.

---

# 3. Resume Management

The system shall allow users to:

- Upload resumes (PDF/DOCX).
- View uploaded resumes.
- Delete resumes.
- Analyze resume content.

---

# 4. Career Analysis

The system shall:

- Identify user skills.
- Detect missing skills.
- Recommend skills to learn.
- Suggest career paths.

---

# 5. Job Recommendation

The system shall:

- Recommend jobs based on user profile.
- Filter jobs by location.
- Filter jobs by experience.
- Filter jobs by salary.

---

# 6. Salary Prediction

The system shall:

- Predict expected salary.
- Display salary insights.
- Show salary trends.

---

# 7. Dashboard

The dashboard shall display:

- Job market trends.
- Popular skills.
- Salary statistics.
- User progress.

---

# 8. AI Features

The system shall provide:

- AI Career Guidance
- Resume Feedback
- Interview Question Generation
- Learning Recommendations

---

# Conclusion

These functional requirements define the core capabilities of Version 1.0 of the AI Career Platform.
