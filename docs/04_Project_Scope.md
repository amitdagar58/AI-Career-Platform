# 1. Project Scope

The AI Career Platform focuses on helping students and job seekers make better career decisions using Artificial Intelligence, Machine Learning, and Data Analytics.

The platform will provide intelligent recommendations and career insights through a web application.

---

# 2. Features Included

The project will include the following features:

- User Authentication
- Resume Upload
- Resume Analysis
- Skill Gap Analysis
- Job Recommendation
- Salary Prediction
- Career Guidance
- Learning Recommendations
- Interview Preparation
- Job Market Analytics Dashboard
- User Profile Management

---

# 3. Features Not Included

The following features are outside the scope of Version 1.0:

- Mobile Application
- Online Job Application System
- Video Interview Platform
- Payment Gateway
- Live Chat with Recruiters
- Company Recruitment Portal

These features may be considered in future versions.

---

# 4. Target Users

The platform is intended for:

- Students
- Fresh Graduates
- Job Seekers
- Career Changers
- Professionals who want career guidance

---

# Conclusion

The project scope clearly defines the features that will be developed in Version 1.0 while keeping the project focused, manageable, and achievable within the planned timeline.
